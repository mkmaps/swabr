# První kroky

Swabr uvede váš Mac do pořádku: odstraní data, která nepotřebujete, úplně odinstaluje aplikace, ukáže, kam mizí vaše úložné místo, a dohlíží na stav vašeho Macu.

## Sekce
| Sekce | K čemu to slouží |
|---|---|
| **Přehled** | Stav vašeho Macu a kolik místa lze uvolnit – přehled všech oblastí na první pohled |
| **Úklid** | Odstraňte mezipaměti, protokoly, zbytky a mezipaměti vývojářů |
| **Aplikace** | Odinstalujte aplikace včetně jejich zbytků, vyhledávejte aktualizace, spravujte položky spouštěné při startu |
| **Optimalizovat** | Údržba pro Finder, síť, databáze a služby macOS |
| **Úložiště** | Zjistěte, které složky a soubory zabírají kolik místa |
| **Stav** | CPU, paměť, disk, síť, baterie a skóre stavu |
| **Projekty** | Odstraňte ze svých projektů složky sestavení, jako jsou node_modules nebo target |
| **Instalátory** | Vyhledejte staré instalační soubory .dmg, .pkg a zip |
| **Zeštíhlit** | Odstraňte kód Intel, který váš Mac nepotřebuje |
| **Historie** | Zjistěte, co všechno Swabr odstranil |

## Jak s tím pracovat
- **Začněte s přehledem:** volba „Zkontrolovat vše“ prohledá najednou slo**žky** „**Úklid**“, „**Projekty**“, „**Instalátory**“ a „**Zeštíhlit**“. Poté vás volba „Zkontrolovat a Úklid“ přenese do oblasti s největším volným místem.
- **Nejprve se podívejte, teprve pak se rozhodněte:** každá sekce nejprve pouze provádí skenování. Nic se neodstraní, dokud nezkontrolujete seznam a nepotvrdíte okno s přehledem.
- **Přečtěte si důsledky:** v každém řádku je uvedeno, co se stane po odstranění. Podívejte se blíže na položky označené oranžově.
- **Nápověda na místě:** tlačítko s otazníkem v pravém horním rohu otevře příslušnou stránku nápovědy.

> Tip: Verze Direct potřebuje jednorázově oprávnění „**Plný přístup k disku**“, jinak zůstanou Koš, Mail a některá data aplikací skryta. Viz „Plný přístup k disku“.
