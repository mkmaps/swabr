# Πρώτα βήματα

Το Swabr φροντίζει ώστε ο Mac σας να είναι πάντα σε άψογη κατάσταση: αφαιρεί δεδομένα που δεν χρειάζεστε, πραγματοποιεί πλήρη απεγκατάσταση των εφαρμογών, δείχνει πού πηγαίνει ο αποθηκευτικός σας χώρος και παρακολουθεί την κατάσταση του Mac σας.

## Οι ενότητες
| Ενότητα | Για ποιο λόγο |
|---|---|
| **Επισκόπηση** | Η κατάσταση του Mac σας και πόσος χώρος μπορεί να απελευθερωθεί, κάθε περιοχή με μια ματιά |
| **Καθαρισμός** | Διαγράψτε προσωρινά αρχεία, αρχεία καταγραφής, υπολείμματα και προσωρινά αρχεία προγραμματιστών |
| **Εφαρμογές** | Απεγκατάσταση εφαρμογών μαζί με τα υπολείμματά τους, βρείτε ενημερώσεις, διαχειριστείτε τα στοιχεία εκκίνησης |
| **Βελτιστοποίηση** | Συντήρηση για το Finder, το δίκτυο, τις βάσεις δεδομένων και τις υπηρεσίες του macOS |
| **Χώρος** | Δείτε ποιοι φάκελοι και ποια αρχεία καταλαμβάνουν πόσο χώρο |
| **Κατάσταση** | Επεξεργαστής, μνήμη, δίσκος, δίκτυο, μπαταρία και βαθμολογία κατάστασης |
| **Έργα** | Διαγράψτε φακέλους κατασκευής όπως το node_modules ή το target από τα έργα σας |
| **Προγράμματα εγκατάστασης** | Εύρεση παλαιών προγραμμάτων εγκατάστασης τύπου .dmg, .pkg και zip |
| **Ελάφρυνση** | Αφαιρέστε τον κώδικα της Intel που δεν χρειάζεται ο Mac σας |
| **Ιστορικό** | Δείτε όλα όσα αφαίρεσε το Swabr |

## Πώς να το χρησιμοποιήσετε
- **Ξεκινήστε με τη γενική επισκόπηση:** η επιλογή «Έλεγχος όλων» αναζητά τα στοιχεία «**Καθαρισμός**», «**Έργα**», «**Προγράμματα εγκατάστασης**» και «**Ελάφρυνση**» ταυτόχρονα. Στη συνέχεια, η επιλογή «Επισκόπηση & Καθαρισμός» σας μεταφέρει στην περιοχή με τον περισσότερο ελεύθερο χώρο.
- **Πρώτα ρίξτε μια ματιά, μετά αποφασίστε:** κάθε ενότητα αρχικά πραγματοποιεί μόνο σάρωση. Τίποτα δεν διαγράφεται μέχρι να ελέγξετε τη λίστα και να επιβεβαιώσετε το παράθυρο ελέγχου.
- **Διαβάστε τις επιπτώσεις:** κάθε σειρά αναφέρει τι συμβαίνει μετά τη διαγραφή. Εξετάστε προσεκτικά τις καταχωρήσεις που είναι επισημασμένες με πορτοκαλί χρώμα.
- **Βοήθεια στη θέση:** το κουμπί με το ερωτηματικό στην επάνω δεξιά γωνία ανοίγει τη σχετική σελίδα βοήθειας.

> Συμβουλή: η έκδοση Direct απαιτεί **Πλήρης πρόσβαση στον δίσκο** μία φορά, διαφορετικά ο Κάδος, το Mail και ορισμένα δεδομένα εφαρμογών παραμένουν αόρατα. Δείτε «Πλήρης πρόσβαση στον δίσκο».
