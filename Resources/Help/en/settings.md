# Settings

## General
Appearance (light/dark/system), language (one of 12 languages or like the system, applies after restart), menu bar, open at login and **online info**.

## Behavior
| Setting | Default | Effect |
|---|---|---|
| Deleted items | permanently | Clean Up deletes right away or moves to the Trash |
| Empty the Trash too | on | Clean Up empties the Trash |
| Preselect "Review" | off | "Recommended" also selects orange entries |
| Leftovers of removed apps after | 30 days | how old leftovers must be |
| Large data sets from | 500 MB | threshold for hints |
| Remove personal data too | off | preselection when uninstalling |
| Remove system files too | off | preselection when uninstalling |
| Projects: recently used | 7 days | newer build folders are not preselected |
| Projects: search depth | 6 levels | how deep to search |
| Time limit per place | 30 seconds | Storage measurement |
| Update interval | 2 seconds | Status and menu bar |

See the matching help topics. "About" shows version and edition.
