# Programmes d’installation

Installers recherche les fichiers d’installation qui ne sont généralement plus nécessaires après l’installation : fichiers .dmg, .pkg, .mpkg, .iso, .xip et archives zip contenant une application.

## Emplacements recherchés
Téléchargements, Bureau, Documents, Public, Bibliothèque/Téléchargements, le cache Homebrew, Téléchargements iCloud, pièces jointes de Mail et Telegram (jusqu’à deux niveaux de profondeur). La version App Store effectue la recherche uniquement dans le dossier Téléchargements.

## Par la suite
Les fichiers sélectionnés sont envoyés dans la Corbeille. Les programmes installés restent en place ; pour les réinstaller, téléchargez à nouveau le programme d'installation. La barre d'espace ou un clic droit permet d'afficher un aperçu.
