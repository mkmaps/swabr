# Cronologia

La Cronologia elenca tutto ciò che Swabr ha rimosso, sposto nel Cestino o alleggerito – raggruppato per esecuzione, con sezione, percorso e dimensione. Cerca per percorso o sezione.

- **"Apri Cestino**" (clic con il tasto destro) ti aiuta a ripristinare gli elementi.
- **"Mostra file di log"** apre il file di testo con tutte le voci.

Il log rimane sul tuo Mac e non viene mai inviato da nessuna parte.
