# Programmi di installazione

Installers cerca i file di installazione che di solito non servono più dopo l’installazione: .dmg, .pkg, .mpkg, .iso, .xip e archivi zip contenenti un’app.

## Posti in cui cerca
Download, Desktop, Documenti, Pubblico, Libreria/Download, la cache di Homebrew, Download iCloud, allegati di Mail e Telegram (fino a 2 livelli di profondità). La versione per App Store cerca solo nella cartella Download.

## In seguito
I file selezionati finiscono nel Cestino. I programmi installati rimangono; per reinstallarli, scarica di nuovo il programma di installazione. La barra spaziatrice o un clic con il tasto destro mostra un'anteprima.
