# Primi passi

Swabr rimette in ordine il tuo Mac: rimuove i dati che non ti servono, disinstalla completamente le app, ti mostra dove va a finire lo spazio di archiviazione e tiene d’occhio lo stato di salute del tuo Mac.

## Le sezioni
| Sezione | A cosa serve |
|---|---|
| **Panoramica** | Lo stato di salute del tuo Mac e quanto spazio puoi liberare: tutte le informazioni a colpo d’occhio |
| **Pulisci** | Elimina cache, log, file residui e cache degli sviluppatori |
| **App** | Disinstalla le app con i loro file residui, trova gli aggiornamenti, gestisci gli elementi di avvio |
| **Ottimizza** | Manutenzione per Finder, rete, database e servizi macOS |
| **Spazio** | Scopri quali cartelle e file occupano quanto spazio |
| **Stato** | CPU, memoria, disco, rete, batteria e un punteggio di integrità |
| **Progetti** | Rimuovi le cartelle di compilazione come node_modules o target dai tuoi progetti |
| **Programmi di installazione** | Trova vecchi file di installazione .dmg, .pkg e zip |
| **Alleggerisci** | Rimuovi il codice Intel che il tuo Mac non utilizza |
| **Cronologia** | Controlla tutto ciò che Swabr ha rimosso |

## Come usarla
- **Inizia dalla panoramica:** “Controlla tutto” esegue la ricerca in “**Pulisci**”, “**Progetti**”, “**Programmi di installazione**” e “**Alleggerisci**” contemporaneamente. Poi “Rivedi e pulisci” ti porta all’area con più spazio disponibile.
- **Prima dai un’occhiata, poi decidi:** ogni sezione esegue solo una scansione iniziale. Nulla viene eliminato finché non hai controllato l’elenco e confermato la finestra di revisione.
- **Leggi le conseguenze:** ogni riga spiega cosa succede dopo la rimozione. Dai un’occhiata più da vicino alle voci contrassegnate in arancione.
- **Aiuto in loco:** il pulsante con il punto interrogativo in alto a destra apre la pagina di aiuto corrispondente.

> Suggerimento: l’edizione Direct richiede una volta l’**Accesso completo al disco**, altrimenti il Cestino, Mail e alcuni dati delle app rimangono invisibili. Vedi “**Accesso completo al disco**”.
