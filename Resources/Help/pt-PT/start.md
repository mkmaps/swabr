# Primeiros passos

O Swabr deixa o seu Mac em ordem: remove os dados de que não necessita, desinstala aplicações completamente, mostra onde o seu espaço de armazenamento é utilizado e mantém-se atento ao estado do seu Mac.

## As secções
| Secção | Para que serve |
|---|---|
| **Visão geral** | O estado do seu Mac e a quantidade de espaço que pode ser libertado, todas as áreas num relance |
| **Limpar** | Remova caches, registos, resíduos e caches de programadores |
| **Apps** | Desinstale aplicações com os seus resíduos, encontre atualizações, faça a gestão dos itens de arranque |
| **Otimizar** | Manutenção do Finder, da rede, das bases de dados e dos serviços do macOS |
| **Armazenamento** | Veja quais as pastas e ficheiros que ocupam quanto espaço |
| **Estado** | CPU, memória, disco, rede, bateria e uma pontuação de integridade |
| **Projetos** | Remova pastas de compilação, tais como «node_modules» ou «target», dos seus projetos |
| **Instaladores** | Encontre instaladores antigos nos formatos .dmg, .pkg e zip |
| **Reduzir** | Remova o código Intel de que o seu Mac não necessita |
| **Histórico** | Consulte tudo o que o Swabr removeu |

## Como trabalhar com esta funcionalidade
- **Comece pela visão geral:** «Verificar tudo» pesquisa «**Limpar**», «**Projetos**», «**Instaladores**» e «**Reduzir**» de uma só vez. Em seguida, «Revisar e limpar» leva-o à área com mais espaço.
- **Analise primeiro, decida depois:** cada secção realiza apenas uma verificação inicial. Nada é eliminado até que tenha verificado a lista e confirmado a janela de revisão.
- **Leia os efeitos:** cada linha indica o que acontece após a remoção. Observe com mais atenção as entradas marcadas a laranja.
- **Ajuda no local:** o botão com o ponto de interrogação no canto superior direito abre a página de ajuda correspondente.

> Dica: a edição Direct necessita de **Acesso total ao disco** uma única vez; caso contrário, o Lixo, o Mail e alguns dados de aplicações permanecem invisíveis. Consulte «Acesso total ao disco».
