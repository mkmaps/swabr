# Primii pași

Swabr îți pune Mac-ul în ordine: elimină datele de care nu ai nevoie, dezinstalează complet aplicațiile, îți arată unde se duce spațiul de stocare și ține sub observație starea de sănătate a Mac-ului tău.

## Secțiunile
| Secțiune | La ce servește |
|---|---|
| **Prezentare generală** | Starea Mac-ului dvs. și cât spațiu poate fi eliberat, fiecare zonă dintr-o singură privire |
| **Curățare** | Eliminați cache-urile, jurnalele, fișierele rămase și cache-urile dezvoltatorilor |
| **Aplicații** | Dezinstalați aplicațiile împreună cu fișierele rămase, găsiți actualizări, gestionați elementele de pornire |
| **Optimizați** | Întreținere pentru Finder, rețea, baze de date și serviciile macOS |
| **Spațiu** | Vedeți ce foldere și fișiere ocupă cât spațiu |
| **Stare** | CPU, memorie, disc, rețea, baterie și un scor de stare |
| **Proiecte** | Eliminați folderele de compilare, cum ar fi „node_modules” sau „target”, din proiectele dvs. |
| **Programe de instalare** | Găsiți vechile fișiere de instalare .dmg, .pkg și zip |
| **Reducere** | Eliminați codul Intel de care Mac-ul dvs. nu are nevoie |
| **Istoric** | Verificați tot ce a șters Swabr |

## Cum se utilizează
- **Începeți cu prezentarea generală:** opțiunea „Verifică totul” caută simultan în „**Curățare**”, „**Proiecte**”, „**Programe de instalare**” și „**Reducere**”. Apoi, opțiunea „Verifică și Curățare” vă duce la zona cu cel mai mult spațiu disponibil.
- **Mai întâi verificați, apoi decideți:** fiecare secțiune efectuează doar o scanare inițială. Nimic nu este șters până când nu verificați lista și nu confirmați fereastra de revizuire.
- **Citiți efectele:** fiecare rând indică ce se întâmplă după ștergere. Acordați o atenție specială intrărilor marcate cu portocaliu.
- **Ajutor în context:** butonul cu semnul întrebării din colțul din dreapta sus deschide pagina de ajutor corespunzătoare.

> Sfat: ediția Direct necesită o singură dată **Acces complet la disc**, altfel Coșul de gunoi, Mail și unele date ale aplicațiilor rămân invizibile. Consultați „Acces complet la disc”.
